# Run protocol (the 20 answers)

| AI | How to open it | Notes |
|---|---|---|
| ChatGPT | Temporary chat (memory off), default model | Write down the model name shown |
| Gemini | Temporary chat, default model | |
| Perplexity | Logged in (logged-out answers often get blocked) | Default model |
| Google AI Mode | `https://www.google.com/search?udm=50&hl=en&gl=us&q=<your question>` | US English results from anywhere |

1. Paste the exact same question every time.
2. New chat for every run. Never hit "regenerate" inside a chat.
3. 5 runs per AI = 20 answers.
4. Copy the full answer, or screenshot it including the sources, before closing.
5. Write down: date, city you ran it from, logged in or not. Location changes the sources.

Re-run every 2 weeks with the same question and settings. Keep each run dated.

20 answers is a snapshot. Call it a test, never a study.
